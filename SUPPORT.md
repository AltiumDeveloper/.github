# Getting help

| I want to… | Go to |
|---|---|
| Get API or SDK access | [Altium Developer Center](https://developer.altium.com/) |
| Learn how something works | [Developer Center documentation](https://www.altium.com/documentation/altium-developer-center) and the API references for [Altium 365](https://docs.developer.altium.com/platform-api-docs/), [Altium Designer SDK](https://docs.developer.altium.com/ad-sdk-docs/) and [Octopart](https://docs.developer.altium.com/octopart-api-docs/), and the MCP server references for [Altium Designer](https://docs.developer.altium.com/ad-mcp-docs/) and [Altium 365](https://docs.developer.altium.com/platform-mcp-docs/) |
| Ask a "how do I…" question | The [Altium Developer forum](https://forum.live.altium.com/#/forums/100271) |
| Report a problem with an API, SDK or MCP server, or ask for a new capability (wrong data, errors, a tool that fails, a missing field or command) | The [Altium Developer forum](https://forum.live.altium.com/#/forums/100271). Include what you ran (the request, the code or the prompt and tool call), what came back, and the time it happened. |
| Report a mistake in something published here (a docs page, an API reference, a sample, a template or a library) | A GitHub issue in that repository |
| Report a security issue | **Not** a public issue. See [SECURITY.md](SECURITY.md) |
| Ask about an Altium product licence, account or subscription | [Altium Support](https://www.altium.com/support) |

Maintainers watch the forum and issues on a best-effort basis. Customers with an Altium support agreement can also go through their usual support channel.
