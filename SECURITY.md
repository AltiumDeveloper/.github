# Security policy

Thank you for helping keep Altium developers and their data safe.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.**

Report them privately instead, through **GitHub private vulnerability reporting**: open the **Security** tab of the affected repository and click **Report a vulnerability**. It is enabled on every public repository in this organization. If you're not sure which repository is affected, report it on [`.github`](https://github.com/AltiumDeveloper/.github/security/advisories/new).

Please include as much of the following as you can:

- the affected repository, package and version (or commit)
- the type of issue (for example token leakage, injection, auth bypass)
- steps to reproduce, or a proof of concept
- the impact you think it has

We aim to acknowledge reports within 3 business days and keep you informed as we investigate.

## Scope

This policy covers the code in the [AltiumDeveloper](https://github.com/AltiumDeveloper) organization: SDKs, client libraries, samples and documentation sites.

Vulnerabilities in Altium products and services themselves (Altium 365, Altium Designer, Octopart, and the API gateways) are also welcome through the same channels. We will route them to the right product team.

## Supported versions

Unless a repository says otherwise, only the latest release (or the default branch, for unreleased projects) gets security fixes.
